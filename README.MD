# SpendWise Budget Tracker

## About the Project

SpendWise is a simple budget tracking website designed to help users record and organize their daily expenses.

The project was created using HTML and CSS. It includes an expense form, an expense table, budgeting tips, and a helpful budgeting video.

## What I Built

### 1. HTML Structure

The `index.html` file contains the structure of the Budget Tracker.

It includes:
- A SpendWise heading and welcome message
- Expense categories
- An Add Expense form
- An expense table
- Budgeting tips
- A budgeting video using an iframe
- A "How to use this tracker" section

### 2. CSS Styling

The `style.css` file controls the visual appearance of the website.

I used:
- A consistent green, white, and light-gray color palette
- Google Fonts using Poppins
- Styled headings and buttons
- Borders and rounded corners
- Padding and margins for spacing
- Alternating colors for table rows
- Styled form inputs and select menus
- A styled budgeting video section

### 3. Table and Form

The expense form allows users to enter expense information such as:
- Expense name
- Amount
- Category
- Date

The expense table displays the recorded expenses with their name, amount, category, and date.

### 4. CSS Box Model

I used the CSS box model throughout the project.

This includes:
- `margin` for space outside elements
- `padding` for space inside elements
- `border` to separate sections
- `border-radius` to create rounded corners

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Project Goal

The goal of SpendWise is to provide a clean and easy-to-use interface for tracking personal expenses and learning basic budgeting habits.
