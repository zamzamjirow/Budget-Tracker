# SpendWise Budget Tracker

## About the Project

SpendWise is a budget tracking application designed to help users understand their monthly spending. The application stores budget and expense information, collects a budget amount from the user, calculates total expenses, and determines the remaining balance.

## What I Built

The project contains:

- A SpendWise financial dashboard
- Expense categories for Food, Transport, Rent, Entertainment, and Utilities
- A monthly budget
- Total expense calculations
- Remaining balance calculations
- JavaScript user input using a prompt
- Console output showing the budget summary
