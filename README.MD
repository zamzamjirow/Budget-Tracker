# SpendWise

SpendWise is a simple budget and expense tracking webpage built using HTML and CSS.

## What I Built

I created a basic expense tracker that allows users to view sample expenses and enter expense information using a form.

## Main Parts

### Expense Categories

The page displays common expense categories such as Food, Transport, and Entertainment.

### Add Expense Form

The form contains:

- Expense name
- Amount
- Category dropdown
- Add Expense button

The category dropdown includes Food, Transport, Rent, Entertainment, and Other.

### Expense Table

The expense table displays:

- Name
- Amount
- Category
- Date

It also contains five sample expense records and a total.

### Multimedia

The page includes a SpendWise logo and an embedded budgeting video.

### How to Use

A collapsible instructions section explains how to use the tracker.

## Technologies Used

- HTML5
- CSS3
